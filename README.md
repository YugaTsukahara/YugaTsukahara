## 🚀 What I'm Building / 開発中のプロジェクト

### ⏱️ TimeRecord
**Plan, record, compare, and reflect on how time is actually spent.**

An Android-oriented application for recording daily plans and actual activities in small time blocks.

The project focuses on making daily recording simple while allowing users to compare plans with actual behavior and export their records for external AI analysis.

**時間の「予定」と「実績」を記録・比較するアプリ。**

日々の記録をできるだけ負担なく行いながら、計画と実際の行動との差を振り返れることを目指しています。記録したデータを外部AIで分析するためのエクスポート機能も実装しています。

`Python` `AI-assisted Development` `Android-oriented`

### 🧠 Thinker
**A tool for recording thoughts first — and letting AI respond later.**

A personal thinking and reflection application built around the idea that **the user's thinking should remain the main character, not the AI**.

Users answer questions independently, preserve their thoughts, and later use AI as a philosophical dialogue and analysis partner.

**「まず自分で考え、AIは後から対話する」ための思考記録アプリ。**

AIが答えを先回りするのではなく、ユーザー自身の思考を主役として記録し、その後AIを分析・対話相手として利用することを重視しています。

`Python` `Generative AI` `Local LLM Experimentation`

「正しい答えを教えるゲーム」ではなく、**問題の背後にある構造を発見し、自分自身で判断する体験**を目指しています。

## 🤖 How I Work with AI / AIとの開発

I see generative AI not simply as a code generator, but as a tool for expanding what an individual developer can design, test, and build.

My current workflow experiments with AI across:

**Idea → Requirements → Design → Implementation → Testing → Debugging → Iteration**

At each stage, I try to keep the final decisions and verification on the human side.

生成AIを単なるコード生成ツールではなく、**個人が設計・検証・開発できる範囲を広げるための開発パートナー**として活用しています。

AIから提案を受けるだけではなく、

**「何を作るか」「なぜその仕様にするか」「実際に正しく動くか」**

を自分で判断・検証することを重視しています。
